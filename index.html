MATH-LWM-AGENT: Efficient Mathematical Tool Agent

First author · Submitted to AAAI 2027
  • Conceived and led a training-free mathematical agent that predicts tool outcomes before execution.
  • Designed a residual controller that turns prediction-execution mismatch into state for subsequent reasoning.
  • Implemented the runtime and integrated Python, SymPy, and verification tools.
  • Led experiment design, ablations, cost accounting, evidence audits, and manuscript preparation.
  • With thinking disabled, improved HMMT by 52.13 percentage points.
  • Improved IMO-AnswerBench by 35.85 percentage points and IMO-ProofBench by 1.22/7.
  • Residual control reduced model calls per correct by 9.41% and joint inference cost by 10.18%.
